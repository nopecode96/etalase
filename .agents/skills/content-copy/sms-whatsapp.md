# Skill: SMS & WhatsApp Automated Copywriting

> **Pre-requisite:** Read `.agents/skills/product-marketing.md` first.

## Rules for Fonnte WA Delivery
1. **Instant Clarity:** State order code and purchased item in the first 2 lines.
2. **Actionable Link:** Place the digital download or Zoom link cleanly on its own line.
3. **Cart Recovery (Pro):** Send friendly, helpful reminder (not aggressive hard-sell) 30 minutes after checkout drop-off.
4. **Tone:** Polite, localized according to buyer locale (`id`, `en`, `ms`, `th`, `vi`).
